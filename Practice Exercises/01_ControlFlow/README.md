## How to work on one

```bash
cd "Practice Exercises/01_ControlFlow/Easy/E1_FixTheGreeting"
dotnet run
```

Every `Program.fs` ends with a small test section. Running it prints `PASS` / `FAIL` per test.
You're done when every line says `PASS`. Don't edit the tests.

To debug, open the `Program.fs` and press **F5** ("Debug current F# project").
